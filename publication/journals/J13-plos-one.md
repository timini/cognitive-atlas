## Adaptation for this manuscript — editorial judgment

Finish human authorship and substantive AI-use disclosure before treating the package as ready. Preserve the distinction between observed maps and population-median geography. Consider removing the exploratory regional significance claims from the main narrative while retaining their estimates and sensitivity results. Keep the long capital list and computational diagnostics as supporting information if this improves readability. The existing public ZIP and now-public GitHub repository supply code and observations. The frozen paper’s repository-privacy wording needs updating; absent archive and reuse-license evidence remain separate issues. Do not invent an author, funding statement, or license to satisfy a checklist.
